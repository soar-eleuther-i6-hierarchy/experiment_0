What each panel shows

Scope
Relations inside a single Matryoshka block, where no block ordering fixes the direction, so it is derived from coverage asymmetry instead. Blocks shown: B0 (128 features), B1 (384 features), B2 (1,536 features), B3 (6,144 features).
Counts per block
Four independent counts per block on a logarithmic axis. directed edges is pairs where coverage is asymmetric enough to call one the parent; survive PMI > 0 and pass S_res are the strict tests applied to those edges; duplicate pairs is pairs whose firing sets are co-extensive, which are recorded as duplicates and never as edges.
Comparing blocks
These are raw counts, and the blocks differ in size, so the number of pairs available to be counted differs with them — a block of n features offers n(n−1) ordered pairs. Divide by that before reading one block against another.
Superparents
One bubble per in-block superparent (6 in total). x is the fraction of its own block it has edges to, y is the fraction of tokens it fires on, and the bubble area grows with its out-degree. Hover gives the global feature index and its child count.
